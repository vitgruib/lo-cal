Use Lo-Cal with your AI

Every event is public data with no key, so any assistant or agent can read it. Pick the level of convenience you want.

1. Ask in one click

Opens your assistant with the question ready and Lo-Cal's data linked: ChatGPT, Claude, Perplexity. For anything else, paste this link and ask "what's on tonight?":

https://vitgruib.github.io/lo-cal/llms.txt

2. Add it as a tool (MCP)

Apps that support MCP servers can search Lo-Cal directly by date, topic, area and free food, instead of reading files. Needs uv; nothing else to install and no account.

Claude Code

claude mcp add lo-cal -- uvx --from "git+https://github.com/vitgruib/lo-cal#subdirectory=mcp-server" lo-cal-mcp

Claude Desktop, Cursor, LM Studio, Windsurf and other MCP apps

Add this to the app's MCP settings file (Claude Desktop: Settings → Developer → Edit Config):

{
  "mcpServers": {
    "lo-cal": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/vitgruib/lo-cal#subdirectory=mcp-server", "lo-cal-mcp"]
    }
  }
}

It gives two tools: search_events and get_event. Small models handle it well: we test it with Claude Haiku. Source.

3. Let a personal agent tell you

Personal agents like Instinct (which you text over iMessage or WhatsApp), OpenClaw or Hermes, and scheduled tasks in ChatGPT or Claude, can check Lo-Cal for you on a schedule. Send your agent something like:

Every weekday at 8am, read https://vitgruib.github.io/lo-cal/data/llms/today.txt and text me the free food on campus and any AI or startup talks, with times and links. Skip days with nothing good.

Swap in the slice that fits: today.txt, tomorrow.txt, weekend.txt, or one topic like topics/free-food.txt and topics/hackathons.txt (the full list is in index.txt). If your agent supports MCP servers, add the one above instead and it can search any date.

For builders

  • llms.txt: what every file and field means.
  • data/llms/: small text slices that fit in one fetch. data/json/: the same slices as JSON.
  • events.json: every upcoming event, rebuilt every 3 hours.
